# Rushdi Mustafa | Software Developer & Information Systems

A professional portfolio website showcasing my journey as a full-stack developer, my technical expertise, and my humanitarian experience with organizations like UNHCR and LWF.



## 🚀 Overview
This project serves as my digital resume and hub for my software engineering projects. It is designed to be high-performance, fully responsive, and visually modern using a "glassmorphism" aesthetic.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3 (Flexbox & Grid), JavaScript (ES6+)
*   **Backend Knowledge:** Node.js, Express, MongoDB
*   **Design:** Custom CSS with Glassmorphism effects
*   **Icons:** FontAwesome

## ✨ Key Features
- **Mobile Responsive:** Fully optimized for all device sizes (Phones, Tablets, Desktops).
- **Project Showcase:** Highlights major work like the Karibu Groceries LTD management system.
- **Humanitarian Background:** Dedicated section for my translation and data collection work with UNHCR.
- **Modern UI:** Features a dark-mode palette (Deep Midnight & Electric Cyan) with smooth transitions.

## 📂 Project Structure
- `index.html` - Homepage and professional summary.
- `about.html` - Detailed background and soft skills.
- `project.html` - Portfolio of technical work.
- `style.css` - Global styles and mobile media queries.
- `/images` - Optimized assets and certificates.
